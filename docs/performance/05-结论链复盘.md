**日期**：2026-11-25

---

## §1 证据强度分级（复盘的度量尺）

此前所有轮次都用「✅ 定案 / ⛔ 推翻」二值标记，**没有区分证据强度**，这是反复的根源。先定尺：

| 级 | 证据类型 | 能做什么 | 不能做什么 |
|---|---|---|---|
| **A** | **双向纯净干预**（增/减两侧都测）+ 位一致或机制闸 | 立论、推翻他论 | — |
| **B** | **单向纯净干预** + 机制闸确认生效 | 只证明该方向 | **不可反向外推** |
| **C** | 相关性、构成比、**恒等式** | 提出假设 | **不可立论、不可推翻 A/B** |
| **D** | 估计、外推、模型预测 | 排序候选 | 不可承诺、不可立论 |

## §3 三次伪推翻的逐一剖析

### 伪推翻①：E-SIM-01「指令占据发射带宽」
- **立论依据**：ALU:HMMA=7.31:1、HMMA 仅 5.59%（**构成比，C 级**）+ 恒等式（**C 级**）。
- **与已有 A 级结论直接矛盾**：E-SELF-11 ⑥ 实测 **`smsp__issue_active` 仅 27.28%**，发射远未饱和。
  「指令占据发射带宽」要求发射接近饱和 —— **两者不可能同真，我当时没做这个对账**。
- **且 E-SELF-11 ⑤ 已用反向夹逼给出 tensor 管线 ≲2.5%**，不依赖保真度。
- **判定**：C 级证据 + 未做一致性检查 ⇒ **伪推翻**。E-ALG-02 后来正确否证了它。

### 伪推翻②：E-ALG-02 引入「并发不足」
- 否证 E-SIM 的部分**是对的**（纯净减指令，弹性 0.058，B 级）。
- 但顺带引入「warp 并发不足（33.20%）」作为主因 ——
  **E-SELF-08 已用双向占用率证据排除，E-SELF-09 标注「否证（第三次）」**。
- **判定**：在正确否证的同时**复活了一个已被 A 级证据三次否证的假设**。

### 伪推翻③：E-OCC-02/03「MLP 不足，100% 定死」
- **减并发 +30.00%** 是干净的 B 级证据，**没问题**。
- 错在两步：
  1. 把 `T = DRAM字节/有效带宽` 五对照 ≤0.2% 当作「机制链闭合」——
     **带宽 ≡ 字节/时间，该式是恒等式（C 级）**，自洽与因果无关。
  2. 由减方向弹性 0.60 **外推**「增并发可获收益」，并据此折算 +5.55%~+12.39%。
- **又重犯 §E-SELF-10 ① 已记录的错误**：拿自由布局纯读屋顶 246.2 当分母，
  算出「61.1%、1.633× 余量」。原文早写着「屋顶 429 GB/s 不可迁移」。
- **判定**：B+C 级 + 单向外推 + 分母不可迁移 ⇒ **伪推翻**。E-ROWS 已否证。

## §4 四类系统性病灶

1. **证据降级不设闸**：允许 C 级（构成比/恒等式）推翻 A 级（双向干预）。
   手册 §7.29「恒等式不是因果模型」**立了但没执行**——因为它只是一条劝告，没有准入检查。
2. **不做跨轮一致性对账**：新主因与已有实测饱和度冲突时无人拦。
   E-SIM 的「发射饱和」vs E-SELF-11 的「27.28%」是**直接矛盾**，本应在立项前就被拦下。
3. **单向弹性外推**：手册 §7.28「弹性必须双向测」立了，但 E-OCC 仍只测减方向就宣称 100%。
4. **已关闭方向无准入闸**：E-REVIEW-01 说「不要再投入」、E-SELF-11 说「不是给这条环调同步/深度/warp 分工」，
   **后续六轮全在这条环上**。重开内核方向那次是合法的（源码可得，前提变了），
   但之后六轮**没有任何新前提**。

## §7 防复发：四道可执行准入闸（已入手册 §7.39）

**闸 1 · 证据分级准入**
新结论要推翻旧结论，**证据等级必须 ≥ 旧结论**。
C 级（构成比/相关性/恒等式）**一律不得推翻 A/B 级**，只能登记为待验假设。

**闸 2 · 跨轮一致性对账（立项前强制）**
立新主因前，列出它与所有已判决结论的冲突点并逐条解释。
**饱和度类断言必须与已有实测饱和度对账**（如「发射饱和」须对上 `issue_active` 实测值）。

**闸 3 · 已关闭方向准入**
进入任何标记「已关闭/不要再投入」的方向前，**书面说明哪个前提变了**。
无新前提 ⇒ 不得立项。（重开内核那次合法：源码可得；之后六轮无新前提。）

**闸 4 · 份额优先于可玩性**
立项前算 Amdahl 与份额（§7 已有）。
**从未归因的最大份额项优先于已有结论的重复确认。**
按此闸，注意力/HC（17.57%，零探索）本就应排在专家内核（42.02%，已查死）之前。

**E-SELF-08/10/11 用 A 级证据给出了正确答案（配平、互为止点、突破口在减少 staging 往返次数）；
