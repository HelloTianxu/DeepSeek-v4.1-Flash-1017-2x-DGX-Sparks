## 当前结论一句话

**当前目标为单流冷前缀 prefill ≥4000 输入 tokens/s；尚未达到，也尚无本轮可复现的新增端到端提速。** 已完成时间与有效算术账、真实专家内核识别、Engram 主机供给/AIO/块层 tag 等待诊断。专家核心仍是最大已测单项成本；Engram 可回收的 GPU 时间、专家内部计算/访存/解码限制和两 rank 关键路径尚未全部闭合。

## 维护契约

1. **现行事实口径只维护在[发现与结论](<01-发现与结论.md>)**。当前进展只摘要和指路，日志保留历史，不把已撤回观点重新写成事实。
2. 【工程实测】必须关联原始记录；【理论推导】必须写公式与前提；【研究假设】必须写判决实验。生产二进制静态核对属于工件证据，不是动态瓶颈证明。
3. 历史实验中的3000/3500目标、尚未批准窗口、计划中工具等是**当时状态**；当前授权与4000目标以[当前进展](<00-当前进展.md>)为准。
4. 原仓库 README 中约2150 tok/s和本轮约1700–1780 tok/s来自不同环境/负载/工具，**不互相替代，不直接相减作回归判决**。
5. 原始 SSE、JSON、trace、负结果和清理记录都是研究资产。修正报告文字不改原始测量。
6. 不把 GPU busy、TFLOPS 单点、静态指令数、API累计时长或跨请求比例当瓶颈判决；不同优化不连乘收益。
7. 本目录更新不等于实验已运行。未达到4000必须如实记录，不以缓存、削工作量或首 token hash相同冒充达标/普遍质量证明。
